# WG Admin Prototype

基于 `E:\IMG_1134.MOV`（约 60 分钟 WG 后台操作录屏）还原的可交互产品原型。

## 启动

```bash
npm install
npm run dev
```

浏览器打开：http://localhost:5173/

## 已覆盖（录像模块树）

### 运营
厅主公告、消息通知（大厅弹窗等）、APP包管理、游戏管理、品牌设置、域名管理、个性化配置、赛事数据、宣传广场、极光推送、埋点归因、头像管理、客服管理、下载站管理、渠道管理（含新增弹窗）、有奖反馈、营销广告

### 游戏
房间游戏、投注记录、会员投注细目、游戏统计、虚拟彩金池、中奖记录轮播

### 会员
所有会员、待剔除会员、主播号、层级设置、会员标签、VIP等级、注册和验证（KYC）、设备管理、大R报表、短信排名

### 代理
代理模式（净盈利设置）、佣金管理、变更记录、推广设置、代理报表、代理数据1/2（含下级充值留存）、俱乐部全套（管理/成员/借还款/保证金/账单/APP）

### 优惠
活动中心、任务中心、幸运转盘、盲盒、实时返水、利息宝、VIP奖励、金融SVIP、公积金、折扣券、优惠明细、领取与审核、信用借款

### 财务
全部充值（充值设置弹窗）、转账/客服代充/银商充值、提现管理（提现设置）、稽核任务、人工拉回、额度丢失、汇率银行、三方支付排名、担保理赔、账变记录

### 查询 / 风控 / 系统
运营统计、导入执行、会员/游戏/财务报表；风控审核/规则/黑名单/设备/IP；账号权限、角色、日志、系统配置、公告

顶部主导航支持完整下拉；工作区支持多标签与批量关闭。

1. 背景与入口

系统模块用于后台访问安全管控。本期开放「IP白名单」，含 IP 名单与浏览器授权码两个子 Tab。

原型入口：/ → 系统 → IP白名单

2. 页面结构

  • 子 Tab：IP白名单 · 浏览器授权码
  • 页头展示后台域名主/备，可复制
  • 公共：日/周/月、统一时间范围选择器、搜索/重置、新增、表格多选、全选当前页、批量操作、分页

3. IP白名单 Tab

关键词字段：IP、操作人、备注

列表列：IP、地区、访问权限（管理后台）、备注、操作人、操作时间、操作（删除/修改）

批量操作：批量删除

4. 浏览器授权码 Tab

关键词字段：授权码、操作人、备注；另有状态下拉：全部 / 使用中 / 未使用 / 已过期

列表列：授权码（可复制）、状态、到期时间、备注、操作（记录/删除）、操作人、操作时间

批量操作：批量延时、批量删除

底部黄色提示：Chrome 插件 / WG加速器；集团授权码可登录集团及下属站点后台。

5. 弹窗

5.1 新增/修改 IP

  • 访问权限：管理后台（勾选）
  • IP地址（必填）；备注 0/40
  • 新增多行时可 + / 删除行

5.2 新增授权码

  • 前缀固定 bm-，后缀 9 位，支持自动生成
  • 授权时间：7天 / 30天 / 90天 / 永久
  • 备注 0/40；温情提示到期失效

5.3 授权码记录

登录时间筛选 + 列表：登录时间、IP、类型（登录/IP变更）、结果。

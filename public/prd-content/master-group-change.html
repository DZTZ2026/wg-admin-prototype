1. 背景与目标

总控报表「集团账变」查看全平台集团资金流水、个人账变与充币订单；与站点后台同结构、不同数据范围。

原型入口：/master → 报表 → 集团账变

1b. 数据范围（总控 vs 站点）

后台数据范围差异
总控后台（本 PRD） 全平台所有集团 / 站点 可按「所属集团」筛选
站点后台 当前登录站点所属集团 仅本集团，无跨集团数据

2. 页面结构

子 Tab：集团账变 · 个人账变 · 充币订单（均带「新」）

公共：日/周/月、统一时间范围、搜索/重置、导出、分页；顶部范围提示条。

3. 集团账变筛选

所属集团（总控专属）+ 站点关键词字段 + 账变类型 / 细项 / 交易对象（与站点侧选项一致）。

4. 个人账变筛选

编号、账变类型（商务佣金返佣等）、交易对象（含钱包）。

5. 充币订单筛选

所属集团（总控）+ 充币/审核时间 + 站点/订单关键词 + 状态 + 订单类型。

6. 时间选择器

统一 FilterRangePicker（今日～上月快捷 + 时分秒 + 清空/确定）。

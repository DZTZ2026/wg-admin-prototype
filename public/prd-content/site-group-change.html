1. 背景与目标

报表模块「集团账变」聚合集团资金流水、个人账变与充币订单查询。总控与站点共用同一套页面结构，数据范围不同。

原型入口：

  • 站点：/ → 报表 → 集团账变（本集团/本站）
  • 总控：/master → 报表 → 集团账变（全平台）

1b. 数据范围（总控 vs 站点）

后台数据范围差异
总控后台 全平台所有集团 / 站点 可按「所属集团」筛选；Mock 含伯乐以外集团数据
站点后台 当前登录站点所属集团 仅本集团账变与充币订单，无跨集团数据

页面结构、筛选项、子 Tab 两侧一致；仅列表数据源与范围提示不同。

2. 页面结构

子 Tab：集团账变 · 个人账变 · 充币订单（均带「新」）

公共：日/周/月快捷、统一时间范围选择器、搜索/重置、导出报表、分页。

3. 集团账变筛选

筛选项选项
所属集团（仅总控）全平台集团列表，可搜索
关键词字段站点ID、所属公司、所属站点、编号
账变类型账单、集团管理、公司管理、站点管理、API管理
账变细项全部、人工增加/扣除、充币、转入/转出、主站/API/马甲包账单、押金增减、极光账单、开站费扣除、账单返利、专业SEO费用、冻结/解冻理赔保证金、赎回保证金、账单结算返现、滞纳金、站点合并余额/押金增减等
交易对象系统、集团、公司、站点

4. 个人账变筛选

  • 编号（文本）
  • 账变类型：全部、商务佣金返佣、我的推荐返佣、转为余额、人工扣除、提币
  • 交易对象：系统、集团、公司、站点、钱包

5. 充币订单筛选

筛选项选项
所属集团（仅总控）全平台集团列表
时间类型充币时间、审核时间
站点关键词公司名称、站点名称、站点ID
订单关键词订单号、交易哈希值、钱包订单号
全部状态待支付、支付成功、支付失败、支付超时
订单类型后台订单、链上转账、保证金充值

6. 时间选择器

原型全局筛选时间范围组件统一为：左侧快捷「今日 / 昨日 / 本周 / 上周 / 本月 / 上月」，支持开始/结束日期时间，底部清空与确定（FilterRangePicker）。

1. 背景与目标

仪表盘为站点后台默认首页，聚合当日经营焦点、实时人数曲线与周期运营指标。

本期目标：可交互原型（筛选切换、指标切换、多系列折线、汇总表）；数据为 Mock。

原型入口：/ → 顶栏「仪表盘」

2. 页面结构

  1. 顶栏全局筛选：全部币种、全部数据
  2. 今日即时焦点（6 张指标卡）
  3. 实时趋势（今日注册 / 当前在线 / 游戏人数）
  4. 运营总览（周/月 + 指标按钮 + 折线 + 汇总表）

3. 今日即时焦点

右侧筛选：全部公司、全部站点。

卡片示例主值副文案
今日新增人数 + 环比%首充 / 代理 / 大R
会员总数累计人数 + 环比%首充总数 / 代理总数 / 大R
充提差额差额(U)今日充值 / 提现及人数
今日投注投注(U)注单数 / 杀率
今日损益损益(U)利润 / 存量 / 会员余额
今日优惠优惠(U)活动参与 / 任务 / 活动

4. 实时趋势

  • Tab：今日注册、当前在线、游戏人数
  • 当前在线额外筛选：全部类型（全部类型 / 正常 / 疑似机器人）；维度（平台 / 国别 / 系统 / 端口）
  • 横轴：当日 00:00～23:00；多系列图例随 Tab 变化（如平台 MG/PG/WG/大厅）

5. 运营总览

5.1 筛选

  • 周期：周 / 月
  • 时间范围：统一时间选择器（今日/昨日/本周/上周/本月/上月 + 时分秒 + 清空/确定）
  • 指标按钮（单选）：新增代理、新增会员、充值次数、充值总额、提现次数、提现总额、首充人数、充值人数、提现人数、每日优惠、投注总额、有效投注、投注人数、损益
  • 投注类指标（投注总额 / 有效投注 / 投注人数 / 损益）显示「游戏类型 / 游戏平台」切换；图例分别为 全部·电子·捕鱼，或 全部·Askmeslot·JDB·MG·PG·WG

5.2 汇总表

行：今日、昨日、本周、上周、本月、上月。

列分组：新增代理；会员(人：注册/充值/首充/大R)；充提（充值总额/提现总额/充提差额）；游戏（投注人数/有效投注/杀率/损益）。

充提差额：正蓝负红；损益：正绿负红。右上角自动刷新：不自动刷新 / 15 / 30 / 60 秒。底部「查看更多」。

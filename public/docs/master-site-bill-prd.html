1. 背景与目标

总控后台由包网服务商运营/财务使用，负责全平台站点账单的结算跟踪、异议处理与确认付款。

本期目标：

  • 实现总控「运营 → 站点账单」9 Tab 原型，与站点后台共用状态机。
  • 总控在待支付 / 已逾期 / 已坏账 / 全部账单执行「确认付款」，账单进入已支付。
  • 站点负责核对与异议；总控不代替站点点「核对无误」。
  • 沉淀可落地的开发 PRD（本页），供正式开发对照。

原型入口：/master → 运营 → 站点账单（蓝色顶栏「包网总控」）

2. 角色与边界

后台使用者数据范围账单职责
总控后台（本 PRD） 包网运营/财务 全平台 确认付款、异议账单编辑、退回待核对、全量查看
站点后台 集团/公司运营 本集团/公司 核对无误、提交异议、查看详情（详见 站点账单 PRD）

总控列表为全平台账单；站点列表仅本集团/公司。同一账单状态在两侧实时一致。

3. 账单状态机

待下发 ──(系统：自然月结束后计算产生)──→ 待核对 │ ├─ 站点：核对无误 ──────────────────────────→ 待支付 │ │ │ ├─ 总控：确认付款 ──→ 已支付 │ └─ 系统：超过次月月底 ──→ 已逾期 │ │ │ ├─ 总控：确认付款 ──→ 已支付 │ └─ 系统：逾期超过 3 个月 ──→ 已坏账 │ │ │ └─ 总控：确认付款 ──→ 已支付 └─ 站点：存在异议 ──→ 存在异议 ├─ 总控/站点：编辑（状态仍为存在异议） └─ 退回待核对 ──→ 待核对

确认付款入口：待支付、已逾期、已坏账、全部账单（仅当该行状态为上述三者之一）。确认后全部账单中该行状态切换为「已支付」，并进入已支付 Tab。

4. 页面结构

导航：运营 → 站点账单

子 Tab（9）：待下发 · 待核对 · 待支付 · 存在异议 · 已逾期 · 已支付 · 已坏账 · 全部账单 · 账单明细

顶部按钮：查看汇率（各 Tab）；导出报表（已支付 / 全部账单 / 账单明细）

底部：待支付可批量确认付款；其余列表展示条数；金额单位说明为 U。

6. 总控侧操作与弹窗

6.1 确认付款

  • 入口：待支付、已逾期、已坏账操作列；全部账单中对应状态行；待支付底部「批量确认付款」
  • 确认文案：确认后账单状态变更为「已支付」，并进入已支付列表
  • 结果：状态 → 已支付；待支付/已逾期/已坏账列表移除；全部账单该行状态改为已支付

6.2 编辑（存在异议）

  • 可改：费用明细、实际支付总额 U、滞纳金、推荐折扣、站长备注
  • 保存后状态仍为存在异议，需再点「退回待核对」才回到站点核对环节

6.3 退回待核对

确认后状态 → 待核对，站点需重新核对无误或再次提出异议。

6.4 详情

与站点后台同一详情弹窗结构（见第 9 节），总控可查看全平台任意账单。

7. 关键业务规则

  1. 待下发：尚未到达结算周期的账单；自然月结束后由系统计算产生，然后移入待核对。
  2. 待核对：已产生的账单，由站点操作核对无误 / 存在异议 / 详情；核对无误 → 待支付；存在异议 → 存在异议。
  3. 待支付：站点只能看详情；总控点「确认付款」→ 已支付。
  4. 存在异议：操作列提供编辑、详情、退回待核对。
  5. 已逾期：当月账单超过次月月底视为逾期，由待支付自动进入；状态由待支付切换为已逾期。
  6. 已支付：总控在待支付、已逾期、已坏账、全部账单点击确认付款后，账单均切换为已支付并进入已支付 Tab。
  7. 已坏账：逾期超过 3 个月视为已坏账；总控仍可确认付款使其进入已支付。
  8. 核对窗口 Tooltip：待核对每月月初 6 号 00:00:00 之后可点击直接确认无误。
  9. 滞纳金：逾期每多 1 天加收账单总额 0.05%/天，上不封顶（暂不收取）。
  10. 状态变更须留痕：操作人、时间、原状态 → 新状态、备注。

8. 筛选、表格与字段

8.1 筛选

  • 账单月份；品牌字段（品牌 ID / 所属公司 / 品牌名称）；站点币种（单选）
  • 已支付 / 全部账单：账单类型（每月账单 / 一次性费用）
  • 全部账单：账单状态
  • 账单明细：月份、主站 ID、币种、游戏类型、厂商名称

8.2 列表列

品牌名称(ID)、品牌数、所属集团、所属公司、账单月份、账单类型、费用明细、实际支付总额 U、滞纳金、三方固定优惠、本月三方阶梯优惠、本月三方生效优惠、推荐折扣、账单状态、站长备注、操作时间、操作人、操作。

增列：待支付逾期倒计时；待核对/存在异议自动无误倒数；已逾期天数；已坏账「坏账总额 U」。

列不固定；斑马纹。已支付绿色；已逾期 / 已坏账 / 存在异议红色。

8.3 金额口径

  • 列表「实际支付总额 U」= 详情弹窗本账单合计，单位 U
  • 账单合计 = 游戏账单 + CDN 流量费 + 线路维护费 + 其他费用 + 费用调整
  • 实际需支付总额 U = 账单合计 + 推荐折扣
  • CDN 上限 = 当月游戏账单 × 10%，超出自动免除
  • 费用调整：财务每月 5 号前人工导入模板

9. 详情弹窗与汇率

  • 页头：所属集团、主站名称(ID)、账单月份、账单状态、站点余额（可刷新）、站长备注
  • 费用指标：游戏账单、CDN 流量费、线路维护费、其他费用、费用调整、账单合计、推荐折扣、实际需支付总额 U（带问号说明）
  • 明细表与小计；提示「*报表金额单位转换时可能存在尾数误差」
  • 查看汇率：基础币种 / 兑换币种 / 站点汇率

10. 留痕与非功能

  • 确认付款、编辑、退回待核对均写入操作人与操作时间。
  • 语言：简体中文；主题：总控蓝色顶栏（#1d39c4）。
  • 原型：本地 Mock，操作以 Message + 状态切换演示。
  • 与站点后台同域：站点 /，总控 /master。

11. 待确认项

  1. 确认付款是否需要谷歌验证码 / 财务二次审核？
  2. 已坏账确认付款后，坏账总额是否清零、财务报表如何回冲？
  3. 总控是否允许在待核对代站点「核对无误」？（原型：不允许）
  4. 逾期/坏账计算时区、以及「超过 3 个月」按自然月还是 90 天？
  5. 滞纳金正式收取后，确认付款金额是否必须含滞纳金？

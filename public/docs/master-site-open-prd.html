1. 背景与目标

总控后台由包网服务商运营/技术使用，负责受理商户开站申请、自行新增开站、推进建站状态，并完成技术/人工审核。

本期目标：

  • 实现总控「开站管理」7 Tab 原型，操作列可直接改变创建中→配置中→待审核→待付款等相关状态。
  • 明确与商户后台的分工：总控推进与审核，商户发起、付款、上线后经营。
  • 沉淀可落地的开发 PRD（本页），供正式开发对照。

原型入口：/master（蓝色顶栏「包网总控」）

2. 角色与边界

后台使用者开站相关职责
总控后台（本 PRD） 包网运营/技术 新增开站、补充资料、站点配置、状态推进、审核、确认到账、强制冻结
商户/集团后台 集团/公司运营 新增站点申请、查看进度、付款、上线后修改/转让
站点后台 单站运营 皮肤/语言等日常运营配置

3. 页面结构

导航：开站管理（顶栏模块，默认打开）

子 Tab（7）：创建中 · 配置中 · 待审核 · 待付款 · 已上线 · 已注销 · 全部站点

顶部按钮规则：

  • 全部站点：展示「新增开站」+ 导出报表等
  • 创建中 / 配置中 / 待付款 / 已上线：不展示「新增开站」

列表增强：增加「来源」列（商户申请 / 总控创建），支持按来源筛选。

4. 数据来源与列表

来源触发初始状态
商户申请商户后台「新增站点」总控受理后进入「创建中」
总控创建总控「新增开站」（可预填 OSS、备域名、商务等）「创建中」

总控列表为全平台站点；商户列表仅本集团/公司。

5. 完整状态机

商户/总控「新增开站」──→ 创建中 │ ├─ 补充资料（商务必填）──→ 待付款 │ └─ 拒绝 → 已拒绝 ▼ 待付款 │ ├─ 确认到账 / 商户付款 ──→ 配置中 │ ├─ 催办 │ └─ 关闭订单 → 待关闭 ▼ 配置中 │ ├─ 站点配置（保存 →「已配置」） │ ├─ 提交审核（仅已配置可提交） │ └─ 退回创建中 ▼ 待审核（开站待技术审） │ ├─ 审核通过 → 已上线 │ ├─ 审核拒绝 → 已拒绝 │ └─ 退回配置中 → 配置中 ▼ 已上线 │ └─ 注销申请 → 注销待技术审 → … → 已注销

6. 各 Tab 操作列与弹窗

6.1 创建中

操作列：补充资料 · 拒绝 · 详情

补充资料保存后进入待付款（不再使用「进入配置中」）。

6.2 待付款

操作列：确认到账 · 催办 · 关闭订单 · 详情

确认到账后进入配置中。

6.3 配置中

操作列：站点配置 · 提交审核 · 退回创建中 · 详情

站点配置保存 →「已配置」；仅已配置可提交审核 → 待审核。

6.4 待审核

操作列：审核通过 · 审核拒绝 · 退回配置中 · 详情

审核通过后进入已上线。

6.5 已上线 / 已注销 / 全部站点

  • 已上线：注销 · 详情（注销申请 → 注销待技术审）
  • 已注销：详情
  • 全部站点：修改 · 强制冻结 · 转让 · 注销 · 记录 · 详情

7. 关键业务规则

  1. 创建中保存「补充资料」（对接商务必填）后进入待付款。
  2. 待付款「确认到账」后进入配置中；商户侧「付款」同理。
  3. 配置中必须先完成「站点配置」并进入「已配置」，才能「提交审核」。
  4. 审核通过直接上线；已上线/全部站点支持「注销」申请。
  5. Toast 提示位置：屏幕垂直居中。
  6. 备注必填场景：拒绝、审核拒绝、关闭订单、退回创建中、退回配置中、注销。
  7. 状态变更须留痕：操作人、时间、原状态→新状态、备注。

8. 字段与状态枚举

8.1 开站状态（节选）

创建中、配置中、已配置、开站待技术审、待付款、已上线、已拒绝、强制冻结、待关闭、已注销…

8.2 站点配置弹窗必填项（总控）

  • 基础信息：站点模式、代理模式、后台域名、OSS 厂商、皮肤/语言/时区、币种（多选）
  • LOGO与活动：长短昼夜 LOGO 上传、活动模版多选
  • 资源授权（多选表格）：场馆授权、存款通道、提款通道、短信/邮件/客服通道
  • 费用：开站费、线路维护费、授信额度、后台白名单类型

8.3 详情弹窗（只读）

  • 创建中、配置中（未「已配置」）：仅展示「基本信息」Tab，隐藏配置类 Tab
  • 已配置及之后（待审核/待付款/已上线/已注销）：展示全部配置 Tab，内容只读不可编辑
  • Tab 栏固定，内容区滚动

8.4 核心列表字段

所属主站、站点类型、站点 ID、站点名称、来源、集团/公司、站点模式、持有人、对接商务、皮肤、币种、时区、后台域名、余额/押金/线路费、合并状态、开站状态、操作人、操作时间、操作列。筛选栏「币种」为复选框多选。

9. 留痕与非功能

  • 每次状态推进写入操作记录（可在「记录」弹窗展示）。
  • 语言：简体中文；主题：总控蓝色顶栏（#1d39c4）。
  • 原型阶段：本地 Mock，操作以 Message/状态切换演示。
  • 与商户后台同域部署：商户 /，总控 /master。

10. 待确认项

  1. 「已配置」是否作为独立 Tab，还是仅作为配置中 Tab 内子状态？（原型：配置中 Tab 内子状态）
  2. 退回配置中后，是否清空已填配置、强制重新「站点配置」？
  3. 审核通过是否拆分一审（system）/ 二审（人工）两个操作按钮？
  4. 待付款「确认到账」是否需谷歌验证码？
  5. 强制冻结是否仅总控可用？

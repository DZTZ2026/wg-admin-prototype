1. 背景与目标

站点后台（商户/集团，如「伯乐 1179」）由集团或公司运营使用。站点账单负责查看本集团账单、在结算后核对金额、提出异议，以及跟踪待支付/逾期/已支付结果。

本期目标：

  • 9 个状态 Tab + 账单明细可交互原型
  • 站点侧完成「核对无误 / 存在异议 / 退回待核对 / 编辑 / 详情」
  • 与总控共用同一套账单状态机；站点不能确认付款

原型入口：/ → 运营 → 站点账单（红色顶栏「包网站点后台」）

2. 角色边界

后台数据范围账单职责
站点后台（本 PRD） 本集团/本公司账单 核对无误、提交异议、编辑异议账单、退回待核对、查看详情
总控后台 全平台账单 确认付款、处理异议编辑、查看全量状态（详见 总控账单 PRD）

原则：账单由系统按自然月结算产生；站点只负责核对与异议；资金确认（确认付款）仅总控可做。

3. 账单状态机

待下发 ──(系统：自然月结束后计算)──→ 待核对 │ ├─ 站点：核对无误 ──────────────────────────→ 待支付 │ │ │ ├─ 总控：确认付款 ──→ 已支付 │ └─ 系统：超过次月月底 ──→ 已逾期 │ │ │ ├─ 总控：确认付款 ──→ 已支付 │ └─ 系统：逾期超过 3 个月 ──→ 已坏账 │ │ │ └─ 总控：确认付款 ──→ 已支付 └─ 站点：存在异议 ──→ 存在异议 ├─ 编辑（调整金额/备注，状态仍为存在异议） └─ 退回待核对 ──→ 待核对（站点重新核对）

系统自动流转不提供人工按钮：待下发→待核对、待支付→已逾期、已逾期→已坏账。

4. 页面结构

路径：运营 → 站点账单

子 Tab（9）：待下发 · 待核对 · 待支付 · 存在异议 · 已逾期 · 已支付 · 已坏账 · 全部账单 · 账单明细

顶部按钮：查看汇率（各 Tab）；导出报表（已支付 / 全部账单 / 账单明细）

底部：待核对可批量核对无误；其余列表展示条数；金额单位说明为 U。

5. Tab 与操作列

6. 站点侧操作说明

6.1 核对无误

  • 入口：待核对操作列；待核对底部「批量核对无误」
  • 规则：每月月初 6 号 00:00:00 之后可点击直接确认无误（Tab 与「账单状态」列 Tooltip）
  • 确认后：状态 → 待支付，写入操作人/操作时间，账单从待核对消失并进入待支付

6.2 存在异议

  • 入口：待核对操作列（全部账单中状态为待核对时同样展示）
  • 弹窗必填「异议说明」，写入站长备注
  • 确认后：状态 → 存在异议，进入存在异议 Tab

6.3 编辑

  • 入口：存在异议操作列
  • 可改：费用明细、实际支付总额 U、滞纳金、推荐折扣、站长备注
  • 保存后状态仍为存在异议，不自动退回待核对

6.4 退回待核对

  • 入口：存在异议操作列
  • 确认后：状态 → 待核对，站点需重新「核对无误」或再次「存在异议」

6.5 详情

各状态列表均可打开详情弹窗（见第 8 节）。站点在待支付/已逾期/已坏账/已支付仅可查看详情，不可确认付款。

7. 筛选、表格与顶部按钮

7.1 列表筛选（非账单明细）

  • 账单月份（月选择）
  • 品牌字段切换：品牌 ID / 所属公司 / 品牌名称 + 文本输入
  • 站点币种：单选（待下发占位文案为「币种」）
  • 已支付 / 全部账单：增加账单类型（每月账单 / 一次性费用）
  • 全部账单：增加账单状态

7.2 账单明细筛选

账单月份、主站 ID、币种（单选）、游戏类型（电子/真人/体育/棋牌）、厂商名称。

7.3 列表列

品牌名称(ID)、品牌数、所属集团、所属公司、账单月份、账单类型、费用明细、实际支付总额 U、滞纳金、三方固定优惠、本月三方阶梯优惠、本月三方生效优惠、推荐折扣、账单状态、站长备注、操作时间、操作人、操作。

按 Tab 增列：待支付「逾期倒计时」；待核对/存在异议「自动无误倒数」；已逾期「已逾期天数」；已坏账「坏账总额 U」。

列不固定（无 left/right freeze）。表格斑马纹。

7.4 状态展示

已支付 / 正常：绿色；已逾期 / 已坏账 / 存在异议：红色。

8. 详情弹窗与汇率

8.1 详情弹窗

  • 页头：所属集团、主站名称(ID)、账单月份、账单状态、站点余额（可刷新）、站长备注
  • 费用指标一行展示：游戏账单、CDN 流量费、线路维护费、其他费用、费用调整、账单合计、推荐折扣、实际需支付总额 U
  • 明细表：品牌、月份、币种、游戏类型、厂商、投注/有效投注/盈亏、抽佣比例、账单金额、厂商专属优惠、优惠后比例、抽佣金额、折算汇率、游戏账单 U、状态
  • 底部小计 + 红色提示：*报表金额单位转换时可能存在尾数误差
  • 筛选：品牌 ID、币种（单选）、游戏类型、厂商名称；支持导出报表
  • 底部仅「取消」关闭

8.2 查看汇率

弹窗表格：基础币种、兑换币种、站点汇率；底部「关闭」。

9. 字段与计算规则

规则说明
账单金额单位列表「实际支付总额 U」= 详情弹窗本账单合计，单位 U
账单合计游戏账单 + CDN 流量费 + 线路维护费 + 其他费用 + 费用调整
实际需支付总额 U账单合计 + 推荐折扣
CDN 流量费上限 = 当月游戏账单 × 10%，超出自动免除；解析数/节点等级等资源名额不参与封顶
其他费用含 CDN(解析数+节点+IP)、埋点归因(ADJ)、极光、CPF 验证、KYC 验证
费用调整财务每月 5 号前人工导入模板生成
滞纳金当月账单超过次月月底视为逾期，逾期每多 1 天加收账单总额 0.05%/天，上不封顶（暂不收取）
核对窗口待核对：每月月初 6 号 00:00:00 之后可点击直接确认无误
逾期待支付账单超过次月月底 → 已逾期
坏账逾期超过 3 个月 → 已坏账

11. 非功能与待确认

非功能

  • 语言：简体中文；主题：红色顶栏 #d72c2c
  • 原型：本地 Mock，状态切换即时反映到各 Tab / 全部账单
  • 与总控同域：站点 /，总控 /master

待确认

  1. 6 号 00:00:00 之前，「核对无误」是置灰还是隐藏？超时未核对是否自动视为无误？
  2. 站点「编辑」是否允许改金额，还是仅允许改异议备注？（原型：金额+备注均可改）
  3. 「退回待核对」是否仅总控可用？（原型：站点也可退回）
  4. 逾期/坏账按自然月还是按 90 个自然日？时区以站点时区还是 UTC+8？
  5. 滞纳金「暂不收取」下线后，是否回写到实际支付总额 U？

1. 背景与目标

商户/集团后台（如「伯乐 1179」）由集团或公司运营使用。开站管理负责发起开站、跟踪进度、完成付款，以及站点上线后的修改/转让/查看。

本期目标：

  • 7 个状态 Tab 可交互原型
  • 新增站点完整表单
  • 全部站点五类操作弹窗：修改、强制冻结、转让、记录、详情
  • 明确商户侧只读阶段 vs 可写阶段

原型入口：/（红色顶栏「包网站点后台」）

2. 角色边界

后台商户侧职责
商户/集团后台（本 PRD）新增站点、查看进度、付款、上线后修改/转让/记录/详情
总控后台受理、建站推进、站点配置、审核、确认到账（详见 总控 PRD）
站点后台皮肤、语言等运营配置（修改弹窗内提示跳转）

原则：待审核阶段商户不可审核，仅可查看记录/详情；创建中～配置中以查看为主；待付款必须可付款；已上线可经营操作。

3. 商户侧开站流程

① 商户/总控：新增开站 → 创建中 ↓ ② 总控商务：补充资料 → 待付款 ↓ ③ 商户：待付款 → 付款 → 配置中 ↓ ④ 总控：站点配置 → 提交审核 → 待审核 → 审核通过 → 已上线 ↓ ⑤ 已上线 / 全部站点：可申请注销

审批留痕（记录弹窗）：一审 system、二审人工（如 tempo），在总控侧完成，商户只读查看。

4. 页面结构

路径：组织管理 → 开站管理

子 Tab：创建中 · 配置中 · 待审核 · 待付款 · 已上线 · 已注销 · 全部站点

全部站点顶部按钮：新增站点 · 新增子品牌（置灰）· 站点合并（置灰）· 导出报表

底部：已上线/全部站点可批量操作（批量导出、批量下线）。

5. Tab 与操作能力

Tab商户操作列说明
创建中详情查看进度（商务补充资料后进待付款）
配置中详情付款后进入；总控完成站点配置
待审核详情不可审核（无「审核」按钮）
待付款付款 · 详情付款成功 → 配置中

全部站点修改 · 强制冻结 · 转让 · 注销 · 记录 · 详情上线后主操作入口

6. 新增站点

触发：全部站点 →「新增站点」

字段类型必填
所属公司下拉（含「无」）是
是否复制站点单选 + Tooltip（9 类配置说明）是
站点名称文本是
站点模式 / 代理方式单选是
站点持有人下拉是
站点安全码 / 确认安全码密码是
后台域名前缀 + .cg.ink是
后台白名单IP / 授权码条件必填
皮肤版式 / 客户端皮肤下拉是
语言 / 语言匹配模式多选 / 单选是
时区 / 币种下拉是
收费标准 / 授信额度只读面板 / 数字额度必填
备注文本域 0/200否

提交后：进入总控受理链路（创建中），商户在对应 Tab 查看进度。

7. 全部站点操作弹窗

修改

  • 只读：集团、公司、站点类型、皮肤、语言匹配、语言、时区、开站费/押金/线路维护费
  • 可编辑：站点名称、持有人、后台域名前缀、备注
  • 橙色提示：皮肤/语言请前往站点后台修改

强制冻结

  • 绿色确认文案（站点名称 + ID）
  • 备注、谷歌验证码（必填）

转让站点

  • 只读：集团、公司、站点名称
  • 转让类型：内部 / 外部；内部需选转让公司；外部提示联系商务
  • 备注、谷歌验证码（必填）

记录

  • 站点档案 + 审批信息（一审/二审）
  • 底部仅「关闭」

详情

  • 三栏摘要（配置 / 财务 / 运营网络）
  • 创建中 / 配置中（未已配置）：仅「基本信息」Tab
  • 待审核及之后（已完成站点配置）：展示开站配置全量 Tab（LOGO/场馆/存提款/通道等），只读
  • 筛选栏「币种」支持复选框多选
  • 底部「关闭」

8. 筛选与表格

全部站点筛选：时间类型、日/周/月、站点 ID/名称、开站状态、合并状态、语言、皮肤版式、客户端皮肤、时区、币种（多选）等。

核心列：所属主站、站点类型、站点 ID、站点名称、集团/公司、模式、持有人、商务、推荐、皮肤、币种、时区、后台域名（主/备+复制）、余额（红）、押金、线路费、合并状态、开站状态（已上线绿）、操作人、操作时间、操作列。

9. 权限矩阵

阶段查看新增付款修改转让审核
创建中/配置中✓————✗
待审核✓————✗
待付款✓—✓——✗
已上线✓✓—✓✓✗
已注销✓————✗

强制冻结：视权限；原型在全部站点保留，正式版可与总控权限对齐。

10. 异常与分支

  • 审核拒绝：商户查看拒绝原因 → 可修改后重新提交
  • 付款超时：待付款 → 待关闭 → 可能已注销
  • 转让：内部（技术审 + 集团审）；外部（联系商务 + 待外部接收）
  • 注销：注销待技术审 → 注销待集团审 → 已注销
